# A3 Minimality And Sequencing

Read-only analysis; no repository file changed.

A3 ranked image resource enforcement, frontend DOM/API characterization, and a
compatibility-import/provider-direction contract as a combined batch. The
frontend proposal matches A2. The architecture proposal is a new
standard-library static contract: retain documented/current facade symbols as
a subset, reject duplicate `__all__` entries, preserve lazy executor exports,
and reject remote-provider edges to Playwright/local crawler infrastructure.
It must not define an exhaustive public API or smoke-import `service.app` in
the current dependency-limited environment.

A3 proposed bounded image reads and decode limits but acknowledged that host/IP
destination policy is blocked and numeric limits would need deliberate values.
Export enforcement, runtime composition, persistence/attribution extraction,
dependency locking, and security/release policy remain deferred. All selected
test-only candidates have R1 nonexistence recovery and hermetic gates.
