# Documentation Index

Read these files in order when taking over the project:

1. `project-map.md`: entry points, active modules, runtime data, and risk areas.
2. `architecture.md`: process model and module responsibilities.
3. `api.md`: HTTP contract used by the static frontend and tools.
4. `task-lifecycle.md`: task queue, resume, recrawl, and failure behavior.
5. `frontend.md`: static console structure and maintenance rules.
6. `config.md`: runtime configuration and environment variables.
7. `mysql-ai-platform.md`: external MySQL tables and sync context.
8. `technical-debt.md`: known debt and safe refactor order.
9. `testing.md`: verification commands.
10. `ai-change-guide.md`: rules for future AI coding agents.

Operational scripts and deployment notes live in `../ops/README.md`.
